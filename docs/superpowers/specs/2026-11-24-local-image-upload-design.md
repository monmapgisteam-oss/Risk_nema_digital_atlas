# Компьютерээс зураг оруулах (демо) — дизайн

## Зорилго
Демо/концепц: хэрэглэгч компьютерээсээ газрын зураг сонгож атласт нэмж,
бусад зурагтай адил галерей болон томруулж харах цонхонд харах.
Порталд (arcgis.ubhub.mn) хадгалахгүй.

## Зорилт
- Толгой хэсгийн toolbar-т "Зураг оруулах" товч.
- Цонх (modal): файл сонгох (JPG/PNG/WebP, нэг дор хэд хэдийг), гарчиг,
  үзүүлэлт (Аюул / Эмзэг байдал / Өртөх байдал), элемент (Аюулаас бусад үед),
  аюулт үзэгдэл, хамрах хүрээ (Улс эсвэл аймаг). Анхны утга нь одоогийн шүүлтүүр.
- Оруулсан зураг тохирох шүүлтүүрийн галерейд гарна, "Таны оруулсан" тэмдэгтэй.
- Оруулсан зургийг устгах боломжтой (карт дээр).
- Хуудсаа refresh хийсэн ч үлдэнэ.

## Зорилт биш
- Порталд оруулах, сервер талд хадгалах, бусад хүнтэй хуваалцах.
- Нэвтрэх эрх.
- Оруулсны дараа мэдээллийг засах (устгаад дахин оруулна).

## Хязгаарлалт
- Vercel дээр серверийн диск рүү бичих боломжгүй → зөвхөн хөтөч.
- Шинэ npm сан нэмэхгүй.

## Арга (сонгосон: A)
- **A. Хөтчийн IndexedDB** — сонгосон. Тохиргоо шаардахгүй; зөвхөн тухайн хөтөч дээр харагдана.
- B. Vercel Blob — бүх хүнд харагдана, гэхдээ Blob сан тохируулах, API бичих
  шаардлагатай, хамгаалалтгүй. Демод хэтэрхий.

## Хэрэгжүүлэлт (миний шийдвэрүүд)
- `src/lib/localMaps.ts`: IndexedDB (`nema-atlas` db, `maps` store) — файл (Blob) +
  мэдээлэл хадгалах, унших, устгах.
- Хадгалсан зураг бүрийг `AtlasItem` болгон хувиргана: `id = "local-<uuid>"`,
  `lang: "mn"`, `mn: true`, `img`/`thumb` = `URL.createObjectURL(blob)`,
  `local: true` (AtlasItem-д нэмэлт талбар).
- `Atlas.tsx`: manifest-ийн items дээр локал зургуудыг нэмж нэгтгэнэ; одоогийн
  шүүлт, эрэмбэ хэвээр ажиллана.
- `UploadDialog.tsx`: шинэ компонент, одоогийн Dashboard/Atlas CSS загвартай.
- Файлын дээд хэмжээ 25MB; өөр төрлийн файлыг татгалзаж мессеж харуулна.

## Гүйцэтгэгчид үлдээсэн
- Цонх, тэмдэг, устгах товчны нарийн загвар.
